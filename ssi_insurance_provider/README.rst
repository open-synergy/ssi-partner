===================
Insurance Provider
===================

This module provides master data management for insurance products and coverage types.

**Models:**

* **Insurance Product Coverage** — categorises the scope of insurance coverage.
* **Insurance Product** — records an insurance product offered by a provider,
  linked to a coverage type and enriched with a rate schedule.

Installation
============

To install this module, you need to:

#. Clone the repository
#. Add the path to your addons path
#. Install the module via Apps menu or CLI
